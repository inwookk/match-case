# match-case

8대8 미팅 파티를 운영하는 웹 앱이에요. 신청, 입금 확인과 번호 부여, 테이블 배정(1시간씩 3라운드), 당일 화면, 파티 후 서로 고르기까지 한 사이트에서 해요. 데이터는 구글 시트에 저장돼요.

## 두 가지 모드

- **시안**: [`config.js`](config.js)의 `apiUrl`이 비어 있으면 가상의 예시 참가자 17명으로 네 화면을 모두 눌러볼 수 있어요. 아무것도 저장되지 않아요.
- **실제 운영**: `apiUrl`에 Apps Script 웹 앱 주소를 넣으면 구글 시트에 저장돼요. 링크의 `#` 뒤로 화면이 정해져요.
  - `#c=초대 열쇠`: 신청 화면
  - `#t=개인 열쇠`: 내 화면(입금 안내, 번호표, 당일 테이블, 파티 후 고르기)
  - `#h=주최자 열쇠`: 주최자 화면

연결 방법은 [`apps-script/SETUP.md`](apps-script/SETUP.md)에 있어요.

## 화면

- **신청**: 기본 정보, 매칭 정보(주최자만 봐요), 대화 카드(같은 테이블에 보여요), 예약금 안내
- **주최자**: 입금 확인과 번호 부여(여 1–8번, 남 9–16번), 대기자 관리, 테이블 배정과 자리 바꾸기, 라운드 진행, 파티 후 연결 현황, 개인 링크 다시 만들기
- **내 화면**: 입금 안내 또는 번호표, 지금 앉을 테이블, 내 동선, 같은 테이블 사람들의 대화 카드
- **파티 후**: 다시 보고 싶은 사람을 3명까지 골라요. 서로 골랐을 때만 인스타가 보여요.

## 개인정보

- 손님 화면에 오는 데이터는 서버가 `logic.guestModel`로 만들어요. 남의 연락처, 종교, 정치 성향, 조건은 브라우저에 아예 오지 않아요.
- 인스타 ID는 서로 골랐을 때만, 그리고 주최자가 결과를 공개한 뒤에만 상대에게 가요. 공개 전에는 몇 번이든 고칠 수 있고, 공개 뒤에는 고칠 수 없어요. 한쪽만 고른 건 주최자만 봐요.
- 개인 열쇠는 시트에 SHA-256 값으로만 저장해요. 잃어버리면 주최자가 새로 만들어요.
- 예약금 계좌는 시트 `설정` 탭에만 있고, 저장소에는 없어요. 신청 화면에도 안 나오고, 주최자가 승인한 사람의 개인 화면에만 보여요.
- 신청 흐름: 신청 → `승인 대기` → 주최자 승인 → `입금 대기`(계좌 보임) → 입금 확인 → `확정`(번호).
- `config.js`의 `stage`가 `'signup'`이면 신청·승인·입금 확인만 열려요. `'party'`로 바꾸면 당일 테이블과 파티 후 화면이 열려요.

## 배정 규칙

- 여자 2명은 자리를 지키고, 남자 2명이 한 조로 라운드마다 옆 테이블로 옮겨요. 3라운드 동안 이성 8명 중 6명을 만나요.
- 1라운드는 가능한 조합을 모두 따져서 정해요. 1라운드 궁합에 가중치 3, 2·3라운드 궁합에 1을 줘요.
- 같은 테이블은 피하고 싶다고 적은 사람과는 어떤 라운드에서도 같이 앉지 않아요.
- 절대 안 되는 조건에 걸리는 짝은 추천하지 않고, 주최자 화면에 경고로 보여줘요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html`, `styles.css` | 화면 구조와 스타일 (transitions.dev 전환 효과 포함) |
| `config.js` | Apps Script 웹 앱 주소 |
| `logic.js` | 매칭·로테이션·입력 검사·손님용 데이터 규칙. 화면과 Apps Script가 같이 써요 |
| `data.js` | 시안용 가상 참가자와 행사 정보 |
| `kit.js` | DOM 도우미, 탭·알림·오류 표시 |
| `api.js` | 웹 앱과 주고받기, 링크 읽기 |
| `form.js` | 신청서 선택지와 입력 읽기 |
| `guest.js` | 내 화면, 파티 후 화면 |
| `host.js` | 주최자 화면 |
| `app.js` | 상태, 모드, 버튼 동작 |
| `apps-script/Code.gs` | 구글 시트 저장소와 웹 앱 API |
| `apps-script/SETUP.md` | 시트 연결 방법 |

## 실행과 테스트

빌드 없는 정적 파일이에요.

```bash
npx serve .
```

규칙 테스트와 서버 테스트:

```bash
node tests/logic.test.js
```

```bash
node tests/apps-script.test.js
```

가짜 구글 시트로 실제 운영 모드를 로컬에서 열어보기. 링크는 `tests/.fake-links.json`에 저장돼요.

```bash
node tests/fake-backend.js --seed
```
