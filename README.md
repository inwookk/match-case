# match-case

8대8 미팅 파티를 운영하는 웹 시안이에요. 신청, 입금 확인과 번호 부여, 테이블 배정(1시간씩 3라운드), 당일 화면, 파티 후 서로 고르기까지 한 페이지에서 눌러볼 수 있어요.

지금은 시안이라 서버 없이 브라우저 안에서만 돌아가요. 새로 고치면 예시 데이터로 돌아가고, 아무것도 저장되거나 보내지지 않아요. 예시 참가자 17명은 모두 가상 인물이에요.

## 화면

- **신청**: 기본 정보, 매칭 정보(주최자만 봐요), 대화 카드(같은 테이블에 보여요), 예약금 안내
- **주최자**: 입금 확인과 번호 부여(여 1–8번, 남 9–16번), 대기자 관리, 테이블 배정과 자리 바꾸기, 라운드 진행, 파티 후 연결 현황
- **당일 화면**: 내 번호표, 지금 앉을 테이블, 내 동선, 같은 테이블 사람들의 대화 카드
- **파티 후**: 다시 보고 싶은 사람을 3명까지 골라요. 서로 골랐을 때만 인스타가 보여요.

## 배정 규칙

- 여자 2명은 자리를 지키고, 남자 2명이 한 조로 라운드마다 옆 테이블로 옮겨요. 3라운드 동안 이성 8명 중 6명을 만나요.
- 1라운드는 가능한 조합을 모두 따져서 정해요. 1라운드 궁합에 가중치 3, 2·3라운드 궁합에 1을 줘요.
- 같은 테이블은 피하고 싶다고 적은 사람과는 어떤 라운드에서도 같이 앉지 않아요.
- 절대 안 되는 조건에 걸리는 짝은 추천하지 않고, 주최자 화면에 경고로 보여줘요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 스타일과 transitions.dev 전환 효과 |
| `logic.js` | 매칭·로테이션·연결 규칙 (화면과 무관한 순수 함수) |
| `data.js` | 시안용 가상 참가자와 행사 정보 |
| `kit.js` | DOM 도우미, 탭·알림·오류 표시 |
| `form.js` | 신청서 선택지와 입력 검사 |
| `app.js` | 상태와 화면 그리기 |

## 실행

빌드 없는 정적 파일이에요. 아무 정적 서버로 열면 돼요.

```bash
npx serve .
```

규칙 테스트:

```bash
node tests/logic.test.js
```

## 배포

폴더를 그대로 Vercel에 올리면 돼요.

```bash
npx vercel --prod
```
