# 구글 시트 연결하기

신청, 입금 확인, 자리, 서로 고르기가 모두 구글 시트 한 개에 저장돼요. 시트에 붙인 Apps Script가 웹 앱이 되어 사이트와 시트를 이어줘요. 처음 한 번만 아래 순서대로 하면 돼요.

## 1. 시트와 스크립트 만들기

1. [sheets.new](https://sheets.new)에서 새 구글 시트를 만들어요. 이름은 아무거나 괜찮아요. 예: `11월 미팅`.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
3. 처음 열리는 `Code.gs` 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](Code.gs) 내용을 붙여 넣어요.
4. 왼쪽 **파일 ＋ → 스크립트**로 새 파일을 만들고 이름을 `logic`으로 해요. 저장소 루트의 [`logic.js`](../logic.js) 내용을 붙여 넣어요.
5. 왼쪽 **프로젝트 설정(톱니바퀴)** 에서 시간대를 `(GMT+09:00) 서울`로 바꿔요.
6. 저장(Ctrl+S)해요.

## 2. setup 한 번 실행하기

1. 위쪽 함수 고르는 칸에서 `setup`을 고르고 **실행**을 눌러요.
2. 권한을 물어보면 본인 계정으로 허용해요. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르면 돼요. 내가 만든 스크립트라서 뜨는 안내예요.
3. 시트로 돌아가면 `설정`, `참가자`, `자리`, `선택` 탭이 생겨 있어요.

## 3. 행사 정보 채우기

`설정` 탭의 **값** 칸을 채워요.

| 항목 | 넣을 것 |
| --- | --- |
| `name` | 행사 이름 |
| `date` | 날짜. 예: `11월 15일 토요일` |
| `start` | 1라운드 시작 시각. 예: `19:00` |
| `place` | 장소 |
| `deposit` | 예약금 금액. 숫자만 |
| `account` | 예약금 받을 계좌. 초대 링크로 들어온 사람에게만 보여요 |
| `refund` | 환불 규칙 |

`invite_code`, `host_key`, `phase`, `phase_started_at`, `round1_json`은 자동으로 채워지니 손대지 마세요.

## 4. 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 골라요.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 두고 배포해요.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
5. 이 저장소의 [`config.js`](../config.js)에서 `apiUrl`에 그 주소를 넣고 푸시하면 Vercel이 다시 배포해요.

'모든 사용자'여야 친구들이 구글 로그인 없이 신청할 수 있어요. 그래서 주소는 누구나 부를 수 있지만, 스크립트는 열쇠가 맞을 때만 정해진 일을 해요.

## 5. 링크 만들기

사이트 주소가 `https://match-case.vercel.app`이라면:

- **초대 링크** (단톡방에 올려요): `https://match-case.vercel.app/#c=` 뒤에 `invite_code` 값
- **주최자 링크** (나만 써요): `https://match-case.vercel.app/#h=` 뒤에 `host_key` 값

주최자 화면의 '행사 정보'에도 초대 링크와 복사 버튼이 있어요. 신청한 사람은 신청이 끝나면 자기 전용 링크(`#t=…`)를 받아요.

## 운영하면서

- **입금 확인**: 주최자 화면에서 **입금 확인**을 누르거나, 시트 `참가자` 탭의 `상태` 칸을 `확정`으로 바꾸면 번호가 자동으로 붙어요. 자리 8개가 다 찬 상태에서 손으로 확정하면 되돌려지고 칸에 메모가 남아요.
- **파티가 끝나면**: 주최자 화면에서 **파티 마치고 선택 열기**를 눌러요. 다들 고르면 **결과 공개하기**를 눌러요. 공개 전에는 아무도 결과를 못 보고, 공개 뒤에는 아무도 더 고칠 수 없어요. 고르는 중에 결과를 보여주면 여러 번 바꿔 내면서 누가 나를 골랐는지 알아낼 수 있어서 이렇게 나눴어요.
- **개인 링크를 잃어버렸을 때**: 주최자 화면에서 그 사람을 펼쳐 **개인 링크 새로 만들기**를 누르고, 새 링크를 카톡으로 보내요. 이전 링크는 막혀요.
- **열 이름은 바꾸지 마세요.** 열 순서를 바꾸거나 내 메모용 열을 새로 추가하는 건 괜찮아요.
- **열쇠가 샌 것 같을 때**: `설정` 탭에서 `invite_code`나 `host_key` 값을 지우고 `setup`을 다시 실행하면 새 열쇠가 생겨요. 예전 링크는 막혀요.
- **파티가 끝나고 2주 뒤**: 신청서에 적은 대로 `참가자`와 `선택` 탭의 행을 지우거나 시트를 통째로 지워요.
- **스크립트를 고쳤을 때**: 내용을 다시 붙여 넣고 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 눌러요. 이렇게 하면 주소가 그대로예요.
- 요청 하나에 보통 1~3초 걸려요. 버튼을 누른 뒤 글자가 반짝이는 동안 기다리면 돼요.
